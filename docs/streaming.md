# Response Streaming

The Agent class supports streaming responses, allowing you to receive and display text as it's generated by the LLM. This provides a better user experience for long responses and real-time applications.

## Basic Usage

### Using chatStream()

The `chatStream()` method is the recommended way to stream responses with automatic history management:

```typescript
import { Agent } from '@tinycrew/Agent';
import OpenAI from 'openai';

const agent = new Agent({
    name: 'StreamingBot',
    goal: 'Provide helpful responses'
}, new OpenAI());

// Stream the response
for await (const chunk of agent.chatStream('Tell me a story')) {
    if (chunk.content) {
        process.stdout.write(chunk.content);
    }
}
console.log(); // New line after streaming completes
```

### Using the onChunk Callback

Alternatively, use a callback for each chunk:

```typescript
let fullResponse = '';

for await (const chunk of agent.chatStream('Hello', '', (chunk) => {
    // This callback is called for each chunk
    if (chunk.content) {
        process.stdout.write(chunk.content);
        fullResponse += chunk.content;
    }
})) {
    // You can also process chunks here
}

console.log('\nFull response:', fullResponse);
```

## StreamChunk Interface

Each chunk yielded by the stream has this structure:

```typescript
interface StreamChunk {
    type: 'text' | 'tool_call_start' | 'tool_call_end' | 'done';
    content?: string;        // Text content (for 'text' and 'tool_call_end' types)
    toolName?: string;       // Name of tool being called
    toolCallId?: string;     // Unique ID of the tool call
    isComplete: boolean;     // True when stream is finished
}
```

### Chunk Types

| Type | Description |
|------|-------------|
| `text` | A fragment of the response text |
| `tool_call_start` | Indicates a tool is about to be called |
| `tool_call_end` | Tool execution completed, includes result in `content` |
| `done` | Stream has completed |

## Low-Level Streaming with performTaskStream()

For more control, use `performTaskStream()` directly:

```typescript
for await (const chunk of agent.performTaskStream(
    'Generate a report',           // Task description
    'Context: Q4 sales data',      // Memory context (optional)
    [                              // Chat history (optional)
        { role: 'user', content: 'Previous question' },
        { role: 'assistant', content: 'Previous answer' }
    ]
)) {
    switch (chunk.type) {
        case 'text':
            process.stdout.write(chunk.content || '');
            break;
        case 'tool_call_start':
            console.log(`\n[Calling tool: ${chunk.toolName}]`);
            break;
        case 'tool_call_end':
            console.log(`[Tool result: ${chunk.content}]`);
            break;
        case 'done':
            console.log('\n[Complete]');
            break;
    }
}
```

## Streaming with Tools

When an agent has tools, the stream handles tool calls automatically:

```typescript
import { Agent } from '@tinycrew/Agent';
import { Tool } from '@tinycrew/utils/types';

const weatherTool: Tool = {
    name: 'GetWeather',
    description: 'Get current weather for a location',
    schema: {
        name: 'GetWeather',
        description: 'Get weather',
        parameters: {
            type: 'object',
            properties: {
                location: { type: 'string', description: 'City name' }
            },
            required: ['location']
        }
    },
    use: async (args) => {
        return `Weather in ${args.location}: Sunny, 72°F`;
    }
};

const agent = new Agent({
    name: 'WeatherBot',
    goal: 'Provide weather information'
}, new OpenAI(), [weatherTool]);

// The stream will yield tool_call_start and tool_call_end chunks
for await (const chunk of agent.chatStream("What's the weather in Paris?")) {
    switch (chunk.type) {
        case 'text':
            process.stdout.write(chunk.content || '');
            break;
        case 'tool_call_start':
            console.log(`\n🔧 Calling ${chunk.toolName}...`);
            break;
        case 'tool_call_end':
            console.log(`✅ Result: ${chunk.content}`);
            break;
    }
}
```

## Events

Streaming emits events for monitoring:

```typescript
import { AgentEvent } from '@tinycrew/utils/types';

// Emitted for each text chunk
agent.on(AgentEvent.STREAM_CHUNK, (data) => {
    console.log('Chunk received:', data.chunk);
});

// Emitted when stream completes
agent.on(AgentEvent.STREAM_END, (data) => {
    console.log('Stream complete');
    console.log('Full text:', data.fullText);
    console.log('Tools used:', data.toolsUsed);
});

// Standard task events also fire
agent.on(AgentEvent.TASK_STARTED, (data) => {
    if (data.streaming) {
        console.log('Streaming task started');
    }
});

agent.on(AgentEvent.TASK_COMPLETED, (data) => {
    if (data.metadata?.streaming) {
        console.log('Streaming task completed');
    }
});
```

## Building a Chat Interface

Example of a simple streaming chat interface:

```typescript
import { Agent } from '@tinycrew/Agent';
import OpenAI from 'openai';
import * as readline from 'readline';

const agent = new Agent({
    name: 'ChatBot',
    goal: 'Have helpful conversations',
    maxHistoryMessages: 20
}, new OpenAI());

const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
});

async function chat(message: string) {
    process.stdout.write('Assistant: ');

    for await (const chunk of agent.chatStream(message)) {
        if (chunk.content) {
            process.stdout.write(chunk.content);
        }
    }

    console.log('\n');
}

function prompt() {
    rl.question('You: ', async (input) => {
        if (input.toLowerCase() === 'exit') {
            rl.close();
            return;
        }

        await chat(input);
        prompt();
    });
}

console.log('Chat started. Type "exit" to quit.\n');
prompt();
```

## Error Handling

Errors during streaming are thrown and can be caught:

```typescript
try {
    for await (const chunk of agent.chatStream('Hello')) {
        process.stdout.write(chunk.content || '');
    }
} catch (error) {
    console.error('Streaming failed:', error.message);
}

// Or listen to the TASK_FAILED event
agent.on(AgentEvent.TASK_FAILED, (data) => {
    console.error('Task failed:', data.error.message);
});
```

## History Management

The `chatStream()` method automatically manages conversation history:

```typescript
// First message - added to history
for await (const chunk of agent.chatStream('Hello')) { /* ... */ }

// Second message - history includes first exchange
for await (const chunk of agent.chatStream('What did I just say?')) { /* ... */ }

// Check history
console.log(agent.getHistoryLength()); // 4 messages
```

## Best Practices

1. **Always consume the stream**: Use `for await...of` to ensure proper cleanup
2. **Handle all chunk types**: Especially if your agent uses tools
3. **Use chatStream() for conversations**: It manages history automatically
4. **Show progress indicators**: Display something during `tool_call_start`
5. **Buffer for rendering**: For UI rendering, consider buffering chunks for smoother display

## Comparison: chat() vs chatStream()

| Feature | `chat()` | `chatStream()` |
|---------|----------|----------------|
| Returns | Complete response string | AsyncGenerator of chunks |
| Real-time output | No | Yes |
| History management | Automatic | Automatic |
| Tool support | Yes | Yes |
| Best for | Simple responses | Long responses, real-time UIs |
